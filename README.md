# Calculator_python-_PROJECT
Smart Calculator Using Python

A modern, GUI-based calculator developed using Python and Tkinter. This project combines essential mathematical operations with a clean, colorful interface, keyboard support, and calculation history to provide a smooth user experience.

 Features

- Basic Arithmetic Operations: Addition, subtraction, multiplication, and division.
- Scientific Operations: Square and square root calculations.
- Keyboard Support: Perform calculations using keyboard inputs.
- Calculation History: Automatically saves previous calculations in a text file.
- Custom GUI: User-friendly graphical interface built using Tkinter.
- Rounded Buttons: Custom-designed rounded-style buttons using Tkinter Canvas.
- Colorful Interface: White buttons with blue text and color-coded function buttons.

 Technologies Used

- Programming Language: Python
- GUI Library: Tkinter
- Mathematical Library: Math
- File Handling: Python file operations

 Installation and Setup

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_LINK

2. Navigate to the Project Folder

cd Smart-Calculator

3. Run the Application

python calculator.py

Note: Python 3 must be installed on your system. Tkinter is generally included with standard Python installations.

 Keyboard Shortcuts
